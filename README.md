## 참여 방식 (모든 스티커 고유 QR)

- 스티커 1장 = 고유 QR 1개 = 룰렛 1번. QR 주소 `play.html?c=017-K4P9XQ` (앞 3자리 = 매장코드)
- 흐름: 휴대폰 번호(010 11자리) 입력 → 룰렛 →
  - **당첨(1~4등)**: "입력하신 휴대폰 번호로 12/28(월)까지 ○○점 포인트가 적립될 거예요" → 끝
  - **꽝(5등)**: 설문 → 응모권 1회 → 룰렛 → 꽝이면 끝 / 1,000P 당첨이면 적립 안내
- 같은 휴대폰 번호로 여러 스티커 참여 가능 (스티커 = 구매 1번)
- **설문·응모권은 휴대폰 번호당 1번** (응모권 1,000P 30%, 선착순 1,200명)
- 이미 쓴 QR을 다시 찍으면 "이미 참여한 QR이에요"
