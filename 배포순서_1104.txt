럭키룰렛 11/4 업데이트 배포 순서 (세 단계를 같은 날 이어서 하세요)

1. GitHub 올리기
   latte-hub/cafein24_event 저장소 → Add file → Upload files
   play.html · index.html · seed.html · README.md · firestore.rules 5개를 덮어쓰기 → Commit

2. Firebase 규칙 게시
   Firebase 콘솔 → Firestore Database → 규칙 탭
   기존 내용을 모두 지우고 firestore.rules 내용을 통째로 붙여넣기 → 게시
   (빨간 오류 표시가 나오면 게시하지 말고 화면을 캡처해서 보내 주세요)

3. 등수 분리 (QR 번호를 이미 서버에 올린 경우만)
   seed.html 접속(@cafein24.co.kr 로그인) → '2-1. 등수 분리' → 등수 분리 시작
   '등수가 남아 있는 스티커 번호'가 0이 되면 끝

4. 확인 (휴대폰으로 테스트 QR 1~2개)
   - 룰렛 돌리기 → 결과가 나오는지
   - 꽝 QR: 창을 닫았다 다시 QR을 찍어도 만족도 조사 버튼이 보이는지
   - 끝나면 admin → QR 초기화로 테스트 기록 정리

※ 1번만 하고 2번을 안 하면 룰렛이 '연결이 불안정해요'로 멈춰요. 반대도 마찬가지예요.
